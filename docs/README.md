# CVee GitHub Pages site

This folder is a static, GitHub Pages-ready marketing, privacy and support site for CVee 1.7 (build 15).

## Before publishing

1. `assets/config.js` is prefilled with the production support email and GitHub publisher profile. Add the final repository URL after the GitHub repository is created if you want a direct repository link.
2. Replace any visible placeholders in `support.html`, `privacy.html`, `privacy-choices.html` and `terms.html`.
3. Commit the `github-site` folder to the branch/folder you use for GitHub Pages.
4. Use the resulting `https://<username>.github.io/<repo>/privacy.html` as the App Store Connect Privacy Policy URL.
5. Use `support.html` as the App Store Support URL and `index.html` as the Marketing URL.

## Pages

- `index.html` — marketing/home page
- `privacy.html` — privacy policy
- `privacy-choices.html` — privacy choices/data deletion guidance
- `support.html` — App Store support page
- `terms.html` — supplemental terms template
- `404.html` — GitHub Pages not-found page
