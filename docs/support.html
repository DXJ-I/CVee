CVee Support

Practical help for importing a CV, exporting documents, using Apple Intelligence features and keeping your data local.

Publishing step: Support is available by email, and the publisher maintains a public GitHub profile for project information and issue reporting.

Common fixes

Import failed

Try exporting the source document again as a normal PDF or Word file. Password-protected PDFs are not supported. For scans, use a clearer copy with readable text.

Apple Intelligence is unavailable

CVee requires a supported device with Apple Intelligence enabled. If the model is unavailable, the rest of the app remains usable.

Export looks different

The Preview tab is designed to use the same document model as the exported PDF. Reopen Preview after making final edits and export again.

Reminders

Interview reminders are scheduled locally. Check iOS notification permissions if a reminder is missing.
